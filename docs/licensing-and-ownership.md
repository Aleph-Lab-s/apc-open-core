# Licensing, provenance and ownership release gate

This public repository includes an Apache License 2.0 license file as the proposed project license. **The presence of the license file is not proof that all source files are legally cleared for public release.**

Before the first public push, the project owner must verify:

1. Aleph Labs (and/or the actual rightsholder) owns or has written permission to publish every APC source file extracted from the supplied OCI image and release archives.
2. Any employee, contractor, collaborator, or prior contributor agreements assign or license the relevant rights to the publishing entity.
3. All embedded code, snippets, generated files, vendored resources, documentation, logos, and test fixtures have compatible licenses and attribution.
4. The NVIDIA-inspired control patch is original APC code or otherwise has appropriate provenance and compatible license. No NVIDIA OpenShell code is asserted to be included here.
5. The dependency license report is generated from the exact release dependency lock / SBOM.
6. Apache-2.0 patent and contribution terms are reviewed and accepted by the rightsholder before outside contributions are merged.
7. Trademarks and product names are used only for truthful compatibility and origin descriptions.

If any of these checks is unresolved, do not publish the affected files. A source release should be intentionally open, not accidentally disclose material the publisher does not have rights to release.
