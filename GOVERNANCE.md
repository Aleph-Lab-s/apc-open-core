# Governance

## Initial phase

APC begins as a maintainer-led open-source project under Aleph Labs. The maintainers curate releases, security policy, roadmap and compatibility. This is an initial operating model, not a claim of an independent foundation or neutral governance body.

## Community input

Issues, discussions, pull requests, design notes and independent reviews are encouraged. Maintainers should label proposals as accepted, rejected, deferred or experimental and record the reasoning for security-sensitive decisions.

## Changes to governance

As contributors and downstream adopters grow, the project should publish a maintainer nomination process, decision-making rules, conflict-of-interest policy, release delegation and security-response coverage. Any move to a foundation or neutral governance should be deliberate and documented.
